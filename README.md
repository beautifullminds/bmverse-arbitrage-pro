# BMverse Arbitrage Pro

Public static GitHub Pages dashboard with profit/loss calculator. This is a demonstration: no live exchange feeds, order execution, or flash loans are enabled.

## Publish
In repository Settings → Pages choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.

Expected URL: https://beautifullminds.github.io/bmverse-arbitrage-pro/

Do not commit API keys or private keys. Live trading requires a secure backend and independent verification.
